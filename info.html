Installation

How to Install APK + OBB Games

  1. Download the APK and OBB Data files from the download page.
  2. Install the APK file (Allow installation from Unknown Sources if prompted).
  3. Extract the downloaded OBB .zip file using ZArchiver or File Manager.
  4. Move the extracted folder into: Internal Storage / Android / obb /
  5. Launch the game and enjoy!
